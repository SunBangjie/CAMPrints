CAMPrints Project Overview

CAMPrints is a hardware-noise driven camera attribution pipeline. This page summarizes the repository layout, main workflows, and how to reproduce the reported results.

Repository: github.com/SunBangjie/CAMPrints

Highlights

  • camprints_sys/ – PyTorch training & evaluation scripts for CAMPrints and PRNU baselines.
  • model/, model_common/ – denoisers, encoders, residual blocks, and utility layers.
  • prnu/ – reference PRNU extraction + matching utilities for hybrid scoring.
  • Evaluation/, Expected_Results/ – ROC plots, spreadsheets, and CSVs to validate results.
  • Plot_Results.ipynb – visualization notebook for score distributions and ROC curves.

Quick Start

  1. Install dependencies: pip install -r CAMPrints/camprints_sys/requirements.txt.
  2. Download encoder & denoiser checkpoints into camprints_sys/saved_models/.
  3. Prepare paired clean/attacked datasets following the documentation in README.md.
  4. Run python camprints_sys/batch_evaluation.py to reproduce ROC curves and metrics.

The root README.md covers dataset layouts, optional PRNU baselines, and instructions for training vs. evaluation modes. Consult it for detailed CLI flags.
